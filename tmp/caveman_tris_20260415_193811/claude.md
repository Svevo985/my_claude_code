.## App Summary

Web-based Tic-Tac-Toe (Tris) game with HTML, CSS, and JavaScript.

## Steps

### Step 1 - `index.html`
Goal: Create the main HTML structure with game board, status display, and restart button.
Key references: HTML5 semantic elements, grid layout container, responsive design classes.

### Step 2 - `styles.css`
Goal: Style the game board with CSS Grid, player tokens (X and O), hover effects, and responsive layout.
Key references: CSS Grid, Flexbox, media queries, CSS variables for theming.

### Step 3 - `script.js`
Goal: Implement game logic including turn management, win detection, draw detection, and restart functionality.
Key references: Event listeners, DOM manipulation, game state object, win condition matrix.

### Step 4 - `README.md`
Goal: Document the project with setup instructions, file descriptions, and usage examples.
Key references: Project structure, installation steps, browser compatibility notes.
